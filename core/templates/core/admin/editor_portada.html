Todavía no hay foto de portada. Súbela en la pestaña «Fotos» y vuelve acá para editarla.

El editor necesita JavaScript. Si no lo ves, la foto se publica tal como se subió.

Arrastra el recuadro para elegir qué parte de la foto se muestra, y tira de sus esquinas para agrandarlo o achicarlo. Lo que queda fuera del recuadro no se publica.
